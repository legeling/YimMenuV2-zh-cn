# 抢劫功能支持矩阵

本文档记录“账号进度 -> 抢劫”中的实际功能范围。判断依据是当前代码中已经注册的命令和菜单入口，不以游戏本身存在某项任务作为菜单已经支持的证据。

## 豪宅与科兹中心豪劫的边界

Rockstar 的简体中文名称是“科兹中心豪劫”。主持任务需要艺术品工作室，但没有豪宅的玩家仍可作为队员加入，因此它不是一个名为“豪宅抢劫”的独立任务。

PR #1014 新增的配置模块写入 `MPX_K26_*` 准备数据，本轮又按社区实现补齐终章辅助。当前提供：

- 主要目标艺术品选择。
- 四项常规采购开关。
- 十六项准备任务开关。
- 次要目标与兴趣点侦察状态。
- 使用筛选后的 `GENERAL_BS`、`GENERAL_BS2`、`ROBBERY_PROG` 和 `POI_BS` 掩码应用推荐配置。
- 完成玻璃切割、关闭激光网格、跳过数据破解、指纹破解和信号节点。
- 自动填写电脑的三位访问代码。
- 站在目标旁触发主要目标或次要目标拿取。

它尚未提供以下能力：

- 修改参与玩家分红。
- 修改主要或次要目标的结算收益。
- 强制玩家准备、快速启动或瞬间完成终章。
- 自动识别终章阶段或在 Script Local 失效后跨版本回退。

“允许单人开始任务”现在还会修改 `fmmc_launcher` 的赌场终章面板人数检查。该补丁只解除面板和启动限制，不能保证所有赌场终章路线都能在缺少队友时正常推进。

当前代码中的 `MANSION_*_OWNED` 和豪宅车库条目仍只用于识别资产及个人载具存储，不得把这部分资产识别写成抢劫功能。

## 科兹中心豪劫扩展条件

补齐剩余能力或确认现有辅助可用前至少需要确认并审查：

1. 任务使用的脚本名称、stats、tunables、Script Globals 和 Script Locals。
2. 任务大厅、参与人数、分红选择和启动流程。
3. 准备任务、主要目标、收益结算和冷却状态。
4. 游戏版本更新后地址失效时的失败行为，避免错误写入其他脚本内存。
5. 中文菜单入口、命令名称、功能说明和风险提示。
6. Windows 构建，以及单人、多人任务流程的实机验证。

## 维护规则

- PR 只更新全局基址、结构体或特征码时，本表只能标记“底层适配”，不能自动把具体抢劫功能标为兼容。
- 新增抢劫支持必须同时更新前端菜单、后端功能、中文文本、本表和对应版本兼容性文档。
- 未完成实机验证的既有功能统一保留“待回归”状态。
